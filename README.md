# Albion Build Creator v0.4.6

Versión 0.4.6 estable.

## Cambios de esta entrega
- Amplía la compatibilidad del importador con respaldos antiguos de builds.
- Admite respaldos con la lista de presets aunque no incluyan composiciones, además de nombres alternativos para las colecciones y campos antiguos de builds.
- Mantiene e incorpora los datos importados sin borrar los datos que ya existen.
- Permite ordenar manualmente presets, composiciones normales y ZvZ.
