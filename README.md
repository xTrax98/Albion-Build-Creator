# Albion Build Creator v0.4.5

Versión 0.4.5 estable.

## Cambios de esta entrega
- Permite ordenar manualmente los presets arrastrando el asa de cada tarjeta.
- Permite ordenar manualmente las composiciones normales y ZvZ con el mismo sistema.
- Guarda los órdenes elegidos y los conserva al volver a abrir la aplicación.
- Mantiene visibles seis presets y permite recorrer los demás con una barra de desplazamiento.
- Reserva espacio para el checkbox de selección para que no tape el nombre.
